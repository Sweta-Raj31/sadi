# OrderFlow — MERN E-commerce & Order Management Platform

Portfolio-grade MERN application demonstrating authentication, RBAC, catalog, inventory, cart, checkout, orders, MongoDB transactions, aggregation, indexes, validation, security middleware and Docker.

## Run
```bash
docker compose up --build
```
Frontend: http://localhost:5173
API: http://localhost:5000/api/v1/health

Demo: admin@orderflow.local / Admin@123
